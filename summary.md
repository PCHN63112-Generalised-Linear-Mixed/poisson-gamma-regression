# Summary
In this lesson we have discussed logistic regression as our first applied example of the GLM framework. We have seen how both multiple regression and ANOVA-style models can easily be implemented for binary outcome variable, broadening the range of measurements that can be used for inferential purposes. As we have seen, GLMs are very simple to apply in `R` using the `glm()` function as a basic extension of the `lm()` function. The harder aspect is *interpretation* of the model coefficients, due to the link function. As we have seen, great care must be taken when interpreting effects on the scale of the odds, as well as taking great care when transforming these values so that they remain sensible and interpretable. Practically, this is the most relevant aspect of binary logistic regression and one that requires some degree of practice. However, this can be made substantially easier by using the `effects` package and `emmeans` to express these effects on the scale of probability. This allows these models to be expressed very simply in terms of the effects each predictor variable has on the probability of a given outcome. Furthermore, logistic regression models can be directly applied to problems of *prediction*, with clear applications in fields such as medical diagnosis and other binary classifications of data. Indeed, it is no wonder that many examples of classification models under the title of "machine learning" are often little more than logistic regression models.
